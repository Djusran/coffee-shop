# 96° Coffee Shop Website

## Cara membuka di Visual Studio Code
1. Extract file ZIP.
2. Buka folder `coffee-website` menggunakan Visual Studio Code.
3. Klik kanan `index.html` lalu pilih **Open with Live Server** jika ekstensi Live Server tersedia.
4. Atau buka langsung file `index.html` melalui browser.

## Struktur
- `index.html` : struktur halaman website
- `style.css` : desain dan responsif mobile
- `script.js` : JavaScript sederhana
- `assets/` : gambar SVG asli dari file ZIP

Keempat gambar disusun berurutan menjadi satu halaman website:
1. Beranda
2. Cerita
3. Galeri / Testimoni
4. Kontak
